📋 设计规则参考

规则 1：查标准确定基板下限和覆板下限

规则 2：不锈钢标准厚度 12/14/16 mm；宽度 1500/2000 mm

规则 3：轧制厚度 = (覆板厚 + 基板厚) × 2 + 0.6

规则 4：板坯厚度 = 立条厚度 + 基板 × 2

规则 5：轧制长度 = ceil(压缩比) × 100 + 200

规则 6：轧宽/板坯宽 × 不锈钢宽 - 成品 ∈ [30, 60]

规则 7：复板 = 基板 - 80

规则 8：占款比 ≤ 1.6


设备约束：翻板机 ≤ 2500mm | 埋弧焊 ≤ 3900mm | 宽板 ≤ 630mm
